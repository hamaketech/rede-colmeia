# 🐝 Rede Colmeia — Brandbook

## 1. Essência da Marca

**Nome:** Rede Colmeia
**Natureza:** Infraestrutura comunitária descentralizada
**Propósito:** Pessoas sustentando pessoas, sem dependência institucional

### Princípios

* Ajuda mútua
* Descentralização
* Ação direta
* Comunidade acima de instituição
* Escalável e replicável

---

## 2. Posicionamento

* Não é ONG
* Não é empresa tradicional
* Não é caridade

**É:**

* Rede ativa de suporte
* Sistema vivo comunitário
* Infraestrutura social aberta

---

## 3. Conceito Visual

* Sistema vivo
* Colmeia como estrutura
* Rede em expansão
* Movimento coletivo

---

## 4. Direção Estética

* Orgânico + tecnológico
* Modular + fluido
* Forte + humano
* Imperfeito controlado (evitar rigidez)
