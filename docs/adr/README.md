# Architecture Decision Records

This directory stores Architecture Decision Records (ADRs) for Rede Colmeia.

## Naming

Use incremental numeric prefixes:

- `0001-architecture-baseline.md`
- `0002-auth-strategy.md`
- `0003-observability-tooling.md`

## Status Values

- proposed
- accepted
- deprecated
- superseded

## Rules

- Create an ADR for architecture-impacting choices.
- Keep one decision per ADR.
- Explain context, alternatives, and consequences.
- Never delete old ADRs; mark them deprecated or superseded.
